Computer algebra usually hides the middle. StepSolver makes the middle its data model.

I

Own the notation

Input is parsed into an immutable, strictly typed AST. Python is never evaluated, and backend objects do not leak into the public API.

II

Name the method

Substitution, integration by parts, power reduction, partial fractions, completing the square: the derivation records the method and its general identity.

III

Check each move

Steps carry verification records for symbolic equivalence, substitution, differentiation, exact arithmetic, or solution-set equivalence.

Local by design

A visual editor,
one command away.

The web interface accepts two-dimensional mathematical notation and shows identities, substitutions, intermediate expressions, and checks in readable math. FastAPI runs the solver locally; this static site is only its front door.

$ git clone https://github.com/DavideGalilei/stepsolver.git
$ cd stepsolver
$ poetry install
$ poetry run stepsolver-web

Serving on http://127.0.0.1:8000

Built for honest output.

StepSolver is early-stage research software. Its strongest area is single-variable calculus with worked derivations. It also exposes algebra, limits, series, matrices, equations, transforms, discrete mathematics, and numerical evaluation.

When a valid problem has no verified result—or needs domain reasoning the engine cannot yet explain safely—it returns UnsolvedResult. A short list of known pedagogy gaps stays visible as strict expected failures in the tests.

Authorship note

This repository was built entirely by language models.

The solver, tests, frontend, documentation, and visual design were produced by LLMs under human direction. Correctness is earned through tests, strict static analysis, symbolic verification, and review—not through a claim about who typed the code.
